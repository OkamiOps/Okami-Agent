# Comunicação 1-3-1

Use ao dar status, reportar resultado ou pedir uma decisão (ótimo via Telegram/Slack).

## A regra
- **1** — uma frase de resumo: o essencial primeiro (o que aconteceu / o que preciso).
- **3** — até três pontos de apoio: contexto, opções ou os fatos que importam.
- **1** — uma recomendação/próximo passo claro (e a pergunta objetiva, se for decisão).

## Estilo
- Direto, sem floreio (combine com a skill `humanizer`). Não enterre a informação importante.
- Se for decisão, deixe a pergunta fácil de responder (sim/não ou opção A/B).

## Conclusão
- [ ] Começa pelo resumo (não pelo contexto).
- [ ] No máximo 3 pontos de apoio.
- [ ] Termina com recomendação/pergunta clara.
